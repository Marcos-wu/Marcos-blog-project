# 装了 Codex 却不知道干什么？试试用它做视频搞钱

> 装完 Codex 只会写代码？那你亏大了。
> 这 6 个 GitHub Skills，能让 Codex 直接参与视频制作全流程——从写脚本、做分镜到剪辑出片。

**先收藏，按需安装，直接开干。**

---

## 一、HyperFrames：一句话生成动效视频

**适合场景：** 产品介绍、动态海报、知识科普、PPT 风格视频

告诉 Codex 一个视频主题，它就能用 HTML + CSS + 动画制作完整的动效视频，最终渲染为 MP4。

不需要剪辑软件，不需要动效基础。一篇文章、一条推文、一段产品文案，丢给它就能变成一条视频。

📦 GitHub：[https://github.com/heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)

---

## 二、Video-Use：让 Codex 帮你剪视频

**适合场景：** 口播、教程、采访视频

把拍摄素材交给 Agent，它能自动帮你：

- 删除停顿、错误片段和口头禅
- 添加字幕和音频处理
- 画面调色与动效包装

经常拍口播、做教程、录采访的人，重点看这个。

📦 GitHub：[https://github.com/browser-use/video-use](https://github.com/browser-use/video-use)

---

## 三、Remotion Skills：用代码批量做视频

**适合场景：** 排行榜、数据周报、产品更新、固定栏目

Remotion 官方出品的 Agent Skills。

让 Codex 用 React 写视频，统一控制画面、字幕、动画和时间轴。一条规则定义好，后续批量生产，风格完全统一。

想做固定栏目、系列内容的创作者，这是你的效率神器。

📦 GitHub：[https://github.com/remotion-dev/skills](https://github.com/remotion-dev/skills)

---

## 四、Generative Media Skills：AI 视频生成工具箱

**适合场景：** 产品广告、UGC 视频、MV、社交媒体短片

覆盖图片、视频、音频三大类 AI 生成能力。

想大量测试 AI 生视频的各种玩法，从这个仓库入手最合适。

⚠️ 部分功能需要配置 MuAPI，会产生生成费用。

📦 GitHub：[https://github.com/SamurAIGPT/Generative-Media-Skills](https://github.com/SamurAIGPT/Generative-Media-Skills)

---

## 五、Videocut-Skills：中文视频剪辑 Agent

**适合场景：** 中文口播、短视频、采访剪辑

专门为中文创作者设计的视频剪辑 Skills。

Agent 能理解中文剪辑需求，协助处理素材、字幕和短视频制作流程。

中文用户想用 Claude Code 或其他 Agent 剪视频，这个必装。

📦 GitHub：[https://github.com/Ceeon/videocut-skills](https://github.com/Ceeon/videocut-skills)

---

## 六、Seedance2-Skill：帮即梦写专业视频提示词

**适合场景：** AI 短片、广告镜头、创意视频

告诉 Codex 一个视频创意，它会帮你设计：

- 逐秒分镜脚本
- 人物动作描述
- 运镜方式
- 对白与音效标注
- @图片、@视频 的素材引用

生成的提示词可以直接丢进即梦 Seedance 2.0 制作核心镜头。

📦 GitHub：[https://github.com/dexhunter/seedance2-skill](https://github.com/dexhunter/seedance2-skill)

---

## 搭配方案：怎么组合最好用

| 用途 | 推荐组合 |
|---|---|
| 文章 / 推文转视频 | HyperFrames |
| 真人口播、采访剪辑 | Video-Use + HyperFrames |
| 批量制作固定栏目 | Remotion Skills + HyperFrames |
| AI 短剧、广告视频 | Seedance2-Skill + 即梦 + Video-Use |
| 大量测试 AI 视频玩法 | Generative Media Skills |

---

## 真正的玩法：串成你自己的工作流

Codex 真正有意思的地方，是你可以把这些 Skills 串成一条完整的视频生产流水线。

以后你只需要说一句：

> **把这篇推文做成一条 45 秒竖版视频，前三秒抓住注意力，添加中文配音和动态字幕，完成后检查画面与音量。**

剩下的——脚本、分镜、提示词、剪辑、包装——全部交给 Codex 一步步完成。

**你的工作只剩一件事：决定做什么内容。**
